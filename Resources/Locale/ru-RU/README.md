# Русская локализация The Darkest Hour

Основная культура игры — `ru-RU`, запасная — `en-US` (`ContentLocalizationManager`): чего нет здесь, показывается по-английски.

## Откуда переводы

- **Ванильные строки и названия прототипов** — из переводов [Corvax](https://github.com/space-syndicate/space-station-14)
  (MIT, © 2017–2026 Space Wizards Federation, © 2021–2026 Corvax) и [CorvaxGoob](https://github.com/space-syndicate/Goob-Station)
  (MIT / AGPL-3.0, по файлам). Перенесены только строки, чей английский оригинал и переменные совпадают с нашими.
- **Наш контент** (`_DarkestHour`, `ss14-ru/prototypes/_DarkestHour`) и прототипы, переименованные у нас
  (должности, оружие, броня, RMC-порты) — переведены для этого проекта.
- Переводы Space Stories (space-stories-mc14) **не используются**: их лицензия запрещает перенос.

## Как добавлять строки

Новые строки пишутся сразу в двух местах: `Resources/Locale/en-US/...` и такой же путь в `ru-RU`.
Названия и описания новых сущностей — в `ru-RU/ss14-ru/prototypes/<путь к yml>.ftl`:

```
ent-ИдПрототипа = название
    .desc = Описание.
```

Запись нужна у каждого прототипа отдельно (движок не берёт перевод у родителя).
